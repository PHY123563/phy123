📌 第一轮 · 基础任务 · 提示词原文 + 核心收获
请帮我写一个基于 Swiper 插件的轮播图 HTML 和 JS 代码。我的具体配置要求如下： 1. 需要实现无缝循环播放（loop: true）。 2. 需要配置自动播放，每 3.2 秒自动翻页（autoplay）。 3. 关键要求：手动操作（滑动或点击）后，自动播放需要停止（即设置 pauseOnMouseEnter 或相关交互逻辑），不要再继续自动播。 4. 底部的圆点分页器需要支持点击切换（pagination，clickable: true）。 5. 轮播图的初始效果（effect）设置为 cube（3D 方块效果）。 请给我一份完整的、可以直接在浏览器运行的代码（包含引入 Swiper 的 CDN 链接、HTML 结构、CSS 和初始化 JS），并加上清晰的中文注释。

核心收获：loop 无缝循环 + autoplay.delay:3200 + disableOnInteraction（手动后停止）+ pagination clickable + effect:'cube'。swiper-bundle.min.js 一键包含所有模块，无需单独引入 Keyboard/Mousewheel/Creative。

Bug 根因 + 修复：① 手动后自动播不停 → 两层保险：disableOnInteraction: true（内置）+ 显式监听 touchStart / pointerDown / slideClick / 点圆点 → 全部 autoplay.stop()；② Cube 看起来扁平 → 自己 CSS 里写了 overflow:hidden 把 3D 面裁掉了，改成 visible 再加 perspective:1200px 给 3D 变换加视距。

📌 第三轮 · creative 自学 · 提示词原文 + transform 四属性解读
我正在学习 Swiper 插件。课堂上老师只讲了 6 种 effect 效果，但我发现 Swiper 官方文档里还有一种叫 creative（创意定义变换） 的效果没有讲。 请帮我参考 Swiper 官方示例（参考链接/路径：swiper/demo/257-effect-creative.html），帮我写一段包含 creativeEffect 的 transform 写法的初始化代码。 具体需求如下： 1. 代码需要包含 prev 和 next 两个方向的 transform 配置。 2. 上一张（prev）：要求实现缩小、左移，并带有轻微的角度旋转。 3. 下一张（next）：要求实现放大、右移进场（参数由你自定义，但要有电影感，比如带一点景深或者透明度变化）。 4. 请结合代码，用通俗的语言详细解释一下 transform 里面的 translate、rotate、scale、opacity 等属性分别控制什么？ 比如改了哪个数值会让卡片移动变快，改哪个数值会让旋转角度变大？

核心收获：creativeEffect.prev/next 两个方向的 transform：translate 管三维位移（Z 越小越远→景深）、scale 管大小、rotate 管 Z 轴平面旋转角度（数值越大角度越大）、opacity 管透明度。默认配方：prev 缩 0.75 + 左移 60% + Z-400 + 转 -12° + 淡出；next 略缩 0.85 + 右移 60% + Z-200 + 转 10°。
