功能一：AI 多轮对话

发送消息 → 流式返回 AI 回复

  1. 在「模型平台」下拉框选择七牛或硅基流动（backend/.env 已配置密钥，API Key 输入框可留空）。
  2. 在输入框输入消息，按 Enter 或点「发送」，按钮变为「思考中…」，状态灯变黄表示请求中。
  3. AI 回复逐字流式渲染，结束后自动写入对话历史。
  4. 继续追问「我刚才问了什么」，模型能答上——多轮记忆生效。

实测：发送「你好，请用一句话自我介绍」，AI 流式回复自我介绍，气泡与状态灯均正常。

💡 工作原理：前端把全部历史消息组成 messages 数组 POST 给后端 /api/phy_chat，后端代理转发到 OpenAI 兼容接口并 SSE 流式回传；接口本身无状态， 「记得上文」全靠每次请求都带上历史消息。

功能二：图像识别

上传图片 → 返回该图片的中文描述

  1. 点输入框左侧 📷 按钮，选择本地图片（模型要求宽高大于 28px）。
  2. 图片自动压缩（最长边 1024px）后出现缩略预览条，可点「移除图片」撤销。
  3. 发送后用户气泡内显示缩略图，后端检测到图片自动改用视觉模型。
  4. 等待返回，结果区显示该图片的中文描述。

实测：上传纯红色图片，模型回复「这张图片是一张纯红色的正方形，没有任何其他图案或元素。」

💡 工作原理：前端把图片读成 base64 data URL，组装成 OpenAI 兼容 content 数组（text + image_url）随 JSON 提交；后端识别到图片消息自动切换 Qwen3-VL 视觉模型（当前平台没有视觉模型时回落硅基流动）。
3

功能三：语音输入与播报

点 🎤 说话 → 文字进输入框；开启朗读 → AI 回复自动播报

  1. 点输入框左侧 🎤 按钮，允许浏览器使用麦克风，按钮变红色呼吸高亮。
  2. 说完再点一次 🎤 结束，识别出的中文文字自动填进输入框。
  3. 点聊天窗口右上角「朗读回复：关」切换为「开」。
  4. 之后每条 AI 回复结束时自动用中文朗读，再次点击开关即停止播报。

实测：点击 🎤 后出现「正在聆听，请说话…」提示气泡，麦克风按钮红色高亮。

💡 工作原理：语音识别用浏览器 Web Speech API（SpeechRecognition，zh-CN） 本地转文字；播报用 speechSynthesis 语音合成朗读——均为浏览器内置能力，不消耗任何 API 密钥， 需在 Edge / Chrome 的 localhost 或 https 环境下使用。
