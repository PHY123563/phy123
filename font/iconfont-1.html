字体图标Icon Font · Font Awesome

把图形铸进字体。每一个图标都是一个字符，由 @font-face 加载的 woff2 / ttf 字体文件绘制，用 class 复用、像文字一样缩放与上色。

字体图标的原理

CDN 的 CSS 已被下载到本地 cdn 目录，随它一同加载字体文件；图标以连字（ligature）映射为字符：

<i class="fa-solid fa-heart"></i>
